# Employee Management System (EMS)

A modern and responsive Employee Management System built to simplify employee management, task allocation, and organizational workflows through an intuitive dashboard.

## Overview

The Employee Management System (EMS) is a web-based application designed to help organizations manage employee-related activities efficiently. It provides a centralized platform for managing employee information, assigning tasks, monitoring progress, and improving team productivity.

The application offers a user-friendly interface with organized dashboards and efficient task management workflows.

## Features

- **User Authentication:** Secure login and role-based access (if implemented).
- **Admin Dashboard:** Centralized dashboard for managing employees and tasks.
- **Employee Dashboard:** Dedicated dashboard for employees to view assigned tasks.
- **Employee Management:** Manage employee information and records.
- **Task Management:** Create, assign, and manage employee tasks.
- **Task Tracking:** Monitor task progress and completion status.
- **Responsive Design:** User-friendly interface across different screen sizes.

## Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Suha673/EMS.git
```

### 2. Navigate to the Project Directory

```bash
cd EMS
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```
